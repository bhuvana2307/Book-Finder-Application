# 📚 StudyHub — Book Search App

A simple and responsive **Book Search Application** built with **React** and **Tailwind CSS** that fetches data from the **Open Library API**.  
Users can search books by **title, author, or subject**, apply **filters** (like publication year, sort order), and view detailed information for each book.

---

## 🚀 Live Demo
🔗 **View App:** [https://react-tailwind-starter-elezbbhm.stackblitz.io/]



---

## 🛠️ Features

- 🔍 Search books by **Title**, **Author**, or **Subject**
- 🎯 Filter results by:
  - Search type
  - Sort order: *Newest, Relevance, or Oldest*
  - Publication year
- 📖 View detailed information about each book
- 💡 Responsive layout using **Tailwind CSS**
- ⚡ Real-time API data from **OpenLibrary.org**
